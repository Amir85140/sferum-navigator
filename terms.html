Пользовательское соглашение

Дата вступления в силу: 27 сентября 2026 года

1. Общие положения

Настоящее Пользовательское соглашение (далее — Соглашение) регулирует отношения между пользователем (далее — Пользователь) и сервисом Sferum Navigator (далее — Приложение), доступным через мессенджер MAX и в виде мини-приложения.

Используя Приложение, Пользователь подтверждает полное согласие с условиями настоящего Соглашения.

2. Предмет Соглашения

Приложение предоставляет Пользователю образовательные инструменты:

• Планировщик подготовки к экзаменам (ОГЭ, ЕГЭ)
• Тренажёр по школьным предметам
• Дневник оценок с анализом успеваемости
• Карточки для изучения иностранных слов
• Конвертер раскладки клавиатуры
• Поиск видеоуроков
• Мотивационные сообщения
• Чат с ИИ-помощником на базе GigaChat

3. Использование ИИ

Ответы ИИ-помощника предоставляются «как есть» и могут содержать неточности. Пользователь обязуется:

• Не использовать Приложение для получения готовых ответов на экзаменах, контрольных работах и иных формах аттестации
• Проверять важную информацию по официальным источникам
• Использовать Приложение исключительно для обучения и тренировки навыков

4. Права и обязанности

Пользователь вправе: использовать все функции Приложения в образовательных целях.

Пользователь обязуется: не передавать свой доступ третьим лицам, не использовать Приложение для противоправных действий.

Администрация вправе: изменять функционал Приложения, приостанавливать работу для проведения технических работ.

5. Ответственность

Администрация не несёт ответственности за решения, принятые Пользователем на основе ответов ИИ-помощника. Администрация не гарантирует стопроцентную точность информации.

Администрация не несёт ответственности за содержание сторонних ресурсов (RuTube, VK Видео, YouTube), ссылки на которые предоставляет Приложение.

6. Интеллектуальная собственность

Все элементы дизайна, логотипы, тексты и код Приложения являются объектами авторского права и охраняются законодательством РФ.

7. Изменение условий

Администрация оставляет за собой право изменять условия Соглашения. Новая редакция вступает в силу с момента публикации.
