# 🤖 Sferum Navigator — ИИ-наставник в MAX на базе GigaChat

**Sferum Navigator** — мини-апп и бот в мессенджере MAX, который помогает школьникам готовиться к ОГЭ и ЕГЭ: объясняет темы, генерирует тренажёры, составляет персональный план, ведёт дневник оценок и поддерживает мотивацию. Всё — на базе **GigaChat (Сбер)**.

🏆 Проект-участник хакатона Sferum (платформа MAX).

---

## 🚀 Быстрый старт (для жюри и проверяющих)

### Вариант 1 — Мини-апп в браузере (без установки)
1. Откройте ссылку на мини-апп: `https://automatic-system-p7gg76p4wqqwf99rj-8000.app.github.dev` (или GitHub Pages репозитория).
2. **«Чат с ИИ»** — задайте любой вопрос по учёбе → ответит GigaChat (формулы рендерятся KaTeX).
3. **«Тренажёр» → «Тест»** — впишите тему (например, *логарифмы*) → «🎲 10 заданий» → ответьте в полях → «🏁 Завершить и проверить».
4. **«Тренажёр» → «Целый вариант»** — выберите ОГЭ/ЕГЭ, год, номер → «📝 Получить вариант» (таймер 235 мин, выход из вкладки заблокирован до завершения).

### Вариант 2 — Бот в MAX
1. Откройте MAX → найдите **@sferumnavigator_bot** → «Запустить».
2. Напишите любое сообщение — бот ответит через GigaChat.
3. 💡 Чат бота и мини-аппа **общий**: сообщение из MAX появится в веб-чате и наоборот (двусторонняя синхронизация).
