# Sferum Navigator

**Бот в MAX с привязанным Mini App**

Решение для хакатона (Трек: Искусственный интеллект в школьных процессах).

## 💡 Суть проекта
Sferum Navigator — это бот в мессенджере MAX, к которому привязан Mini App. 
Ученик может общаться с ботом в обычном чате, а может нажать кнопку и открыть удобный веб-интерфейс (Mini App) прямо внутри MAX.

##  Как связаны Бот и Mini App?
1. **Бот (`max_bot.py`)** отвечает на сообщения в чате, используя нейросеть GigaChat.
2. К каждому ответу бот прикрепляет кнопку **«Открыть Mini App»**.
3. При нажатии на кнопку внутри MAX открывается веб-интерфейс (`main.py`), где ученик может удобно составить расписание или пройти тест.

##  Функции ИИ (GigaChat)
- **Метод Сократа:** Бот не дает готовых ответов на домашку, а задает наводящие вопросы.
- **Контекст:** Бот помнит, какую тему смотрел ученик, и объясняет именно её.
- **Планировщик:** Помогает разбить задачи на время.

##  Структура проекта
- `main.py` — Веб-интерфейс (Mini App). Открывается по кнопке из бота.
- `max_bot.py` — Логика бота в чате. Отвечает на сообщения и отправляет кнопку Mini App.
- `services.py` — Мозги проекта (подключение к GigaChat и логика ответов).
- `requirements.txt` — Библиотеки для запуска.
- `Dockerfile` — Для сборки проекта.
