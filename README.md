#  Sferum Navigator — ИИ-наставник для школьников

**Mini App для платформы MAX/Сферум**

Решение для хакатона «Идея фикс» (Трек: Искусственный интеллект в школьных процессах).

## 📌 Что это такое?

Sferum Navigator — это **Mini App** (веб-приложение), которое интегрируется в мессенджер MAX/Сферум и помогает школьникам:
- 📅 **Планировать учёбу**: бот спрашивает свободное время и составляет щадящее расписание
-  **Получать помощь с домашкой**: ИИ-наставник объясняет темы методом Сократа (не даёт готовых ответов, а направляет)
- 🎥 **Смотреть видеоуроки**: интеграция с RuTube и VK Видео
- 📝 **Проверять знания**: генерация тестов по темам

## 🎯 Проблема, которую решаем

1. Школьники испытывают стресс из-за дедлайнов и не умеют планировать время
2. При просмотре видеоуроков возникают вопросы, но некому задать их «по контексту»
3. Обычные ИИ-помощники дают готовые ответы, что мешает реальному обучению
4. Существующие сервисы разрознены: журнал в одном месте, видео в другом, ИИ-помощники не знают расписания ученика

## 💡 Наше решение

**Sferum Navigator** — это единая точка входа для школьника внутри привычного мессенджера MAX/Сферум:

### Умный планировщик
- Спрашивает: *"Сколько времени у тебя есть?"*
- Составляет щадящее расписание со ссылками на видеоуроки
- Учитывает сложность предметов и связи между темами

### Контекстный ИИ-наставник (GigaChat)
- Помнит, какие темы ученик смотрел
- Если ученик пишет *"Я не понял"*, бот объясняет именно эту тему
- Использует метод Сократа: задаёт наводящие вопросы, помогает разобраться самому
- Не даёт готовых ответов на домашку

### Метод Сократа
Вместо *"Ответ: 42"* бот говорит: *"Давай разберёмся вместе. Что мы знаем из условия задачи? Какую формулу можно применить?"*

## 🛠 Технологии

- **Python 3.14** + **FastAPI** (высокая скорость отклика)
- **GigaChat API** (российская нейросеть от Сбера)
- **Docker** (гарантия стабильного развертывания)
- **Mini App формат** (бесшовная интеграция в MAX/Сферум)
