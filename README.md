# 🤖 Sferum Navigator — инструкция по запуску и проверке

Мини-апп и бот для мессенджера MAX на базе GigaChat:
план подготовки к ОГЭ/ЕГЭ, тренажёры, целые варианты ФИПИ с автопроверкой,
дневник оценок с ИИ-анализом, чат с ИИ, решение задач по фото, видеоуроки,
мотивация, магазин скинов.

---

## 🔑 О ключах и данных (важно для проверяющих)

- Ключи GigaChat API и токен бота MAX УЖЕ встроены в код
  (файлы proxy_server.py и max_bot.py).
- Проверяющие работают с ключами и демо-данными команды —
  регистрироваться и создавать свои ключи НЕ нужно. Это сделано намеренно.
- В репозитории лежат демо-данные: navigator.db, user_data.json, chat_sync.json
  (оценки, прогресс, история чата) — чтобы сразу увидеть рабочие сценарии.
- Если нужен «чистый старт»: удалите эти три файла и перезапустите —
  приложение создаст их пустыми автоматически.

## 🚀 ЗАПУСК (4 действия: открыть → скачать → запустить → открыть)

### 1. Открой среду разработки
- Страница репозитория на GitHub → зелёная кнопка Code →
  вкладка Codespaces → New codespace
- Подожди 1–3 минуты, пока откроется редактор

### 2. Открой терминал
Сверху: Terminal → New Terminal

### 3. Скачай библиотеки (один раз)
    pip install -r requirements.txt

### 4. Запусти всё одной командой
    bash start_all.sh
Успех = в конце видно {"status":"ok",...}, <!DOCTYPE html> и строку «✅ Готово…»

### 5. Открой мини-апп
Внизу редактора вкладка PORTS → порт 8000 → иконка глобуса → Open in Browser
Адрес вида https://<имя-codespace>-8000.app.github.dev уже вшит в настройки
бота MAX — апп работает и внутри мессенджера.

---

## 🔁 Если codespace уснул или перезагрузился
Просто повтори: bash start_all.sh
Библиотеки и ключи уже на месте.

## 💻 ЗАПУСК НА СВОЁМ КОМПЬЮТЕРЕ (Windows / macOS / Linux)

1. Установи Python 3.10+ (python.org; на Windows галочка Add Python to PATH)
   и Git (git-scm.com).
2. Скачай проект:
       git clone https://github.com/Amir85140/sferum-navigator.git
       cd sferum-navigator
3. Установи библиотеки:
       pip install -r requirements.txt
4. Запусти в ДВУХ окнах терминала:
       python proxy_server.py
       python max_bot.py
5. Открой в браузере: http://localhost:8000
Примечание: для работы аппа внутри MAX нужен публичный адрес,
поэтому основной способ — Codespaces (раздел выше).

## 🐳 ЗАПУСК ЧЕРЕЗ DOCKER (номинация «Продвинутая разработка»)

### Сборка образа
    docker build -t sferum-navigator .

### Запуск контейнера
    docker run -p 8000:8000 sferum-navigator

### Пример полной сессии через командную строку
    git clone https://github.com/Amir85140/sferum-navigator.git
    cd sferum-navigator
    docker build -t sferum-navigator .
    docker run -p 8000:8000 sferum-navigator
    # затем открыть в браузере: http://localhost:8000

Внутри контейнера стартуют сервер с мини-аппом (порт 8000)
и бот MAX в фоновом режиме. Ключи уже встроены в код.

## 📌 ИНФОРМАЦИЯ ДЛЯ ПРОВЕРЯЮЩИХ (ЖЮРИ)

### Быстрый запуск (2 команды)
    docker build -t sferum-navigator .
    docker run -p 8000:8000 sferum-navigator
Затем открыть http://localhost:8000

### Демо-сценарий для проверяющих (3 минуты)
1. Главная: геймбар (уровень, XP, стрик), карточка «Сегодня».
2. Чат: «привет, объясни дроби» → ответ GigaChat;
   «матан 5 4» → оценка падает в дневник.
3. Дневник: график среднего балла + ИИ-анализ слабых предметов.
4. Тренажёр: «Целый вариант» → ОГЭ, Математика, №3 →
   автопроверка с эталонами после завершения.
5. План: составить план недели → сдвиг расписания одним нажатием.
6. Фото-решалка: отправить фото задачи → пошаговое решение (vision GigaChat).

Доступ жюри выдаёт капитан команды: GitHub → Settings → Collaborators → Read.

## 🩺 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

| Симптом | Решение |
|---|---|
| Страница не открывается | bash start_all.sh ещё раз + Ctrl+Shift+R в браузере |
| {"detail":"Not Found"} | Ctrl+Shift+R (жёсткое обновление) |
| Ошибки при установке библиотек | Повтори pip install -r requirements.txt |
| Бот молчит в MAX | tail -30 bot.log — посмотри лог |
| Контейнер не стартовал | docker logs <имя_контейнера> — посмотри лог |
| Ничего не помогло | github.com/codespaces → Delete → New codespace |

## 📁 ФАЙЛЫ ПРОЕКТА

| Файл | Что это |

| terms.html, privacy.html | Юридические страницы аппа |
