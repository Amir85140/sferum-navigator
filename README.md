# Sferum Navigator — ИИ-наставник для школьников

**Бот в MAX с привязанным Mini App**

Решение для хакатона «Идея фикс» (Трек: Искусственный интеллект в школьных процессах).

##  Что это такое?

Sferum Navigator — это **бот в мессенджере MAX/Сферум с привязанным Mini App**, который помогает школьникам:

###  Бот в чате
- Отвечает на сообщения в реальном времени
- Использует GigaChat (российская нейросеть от Сбера)
- Применяет метод Сократа (не даёт готовых ответов)

###  Mini App (веб-интерфейс)
- Открывается по кнопке в боте
- Удобный интерфейс для планирования и обучения
- Визуальное расписание, тесты, прогресс

## 💡 Ключевые идеи

### 1. Умный планировщик
- Бот спрашивает: *"Сколько времени у тебя есть?"*
- Составляет щадящее расписание со ссылками на видеоуроки
- Учитывает сложность предметов и связи между темами

### 2. Контекстный ИИ-наставник (GigaChat)
- Помнит, какие темы ученик смотрел
- Если ученик пишет *"Я не понял"*, бот объясняет именно эту тему
- Использует метод Сократа: задаёт наводящие вопросы
- Не даёт готовых ответов на домашку

### 3. Метод Сократа
Вместо *"Ответ: 42"* бот говорит: *"Давай разберёмся вместе. Что мы знаем из условия задачи? Какую формулу можно применить?"*

### 4. Интеграция с видеоуроками
- Ссылки на RuTube и VK Видео по темам
- Бот рекомендует видео, если ученик не понял тему
- Контекстные подсказки во время просмотра

### 5. Генерация тестов
- Бот создаёт тест по любой теме
- Проверяет знания после изучения темы
- Даёт обратную связь по результатам

### 6. Мотивация и поддержка
- Если ученик пишет *"Я устал"*, бот поддерживает
- Предлагает перерыв или лёгкое задание
- Помогает втянуться в учёбу

##  Проблема, которую решаем

1. Школьники испытывают стресс из-за дедлайнов и не умеют планировать время
2. При просмотре видеоуроков возникают вопросы, но некому задать их «по контексту»
3. Обычные ИИ-помощники дают готовые ответы, что мешает реальному обучению
4. Существующие сервисы разрознены: журнал в одном месте, видео в другом, ИИ-помощники не знают расписания ученика

## 🛠 Технологии

- **Python 3.14** + **FastAPI** (высокая скорость отклика)
- **GigaChat API** (российская нейросеть от Сбера)
- **Docker** (гарантия стабильного развертывания)
- **VK Bot API** (интеграция с MAX/Сферум)
- **Mini App формат** (веб-интерфейс внутри мессенджера)
