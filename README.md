# Sferum Navigator

**Mini App для платформы MAX/Сферум**

Решение для хакатона «Идея фикс» (Трек: Искусственный интеллект в школьных процессах).

## 💡 Что это такое?

Sferum Navigator — это **Mini App** (веб-приложение), которое открывается внутри мессенджера MAX. Помогает школьникам учиться без стресса, используя российскую нейросеть GigaChat.

## 🎯 16 режимов ИИ

1. ** Общий помощник** — ответы на любые вопросы
2. **📅 Подготовка к экзаменам** — составляет план подготовки, спрашивает детали, контролирует прогресс
3. **📝 Помощь с домашкой** — метод Сократа, не даёт готовых ответов
4. **🎓 Объяснение темы** — подробно и с примерами
5. **✅ Проверка знаний** — генерирует тесты с вариантами ответов
6. **💪 Мотивация и поддержка** — эмоциональная помощь
7. **🎥 Видеоуроки** — ссылки на RuTube и VK Видео
8. **📊 Мой прогресс** — аналитика обучения
9. **⏰ Дедлайны** — напоминания о контрольных
10. **🎯 Адаптивное обучение** — подстройка под темп ученика
11. **👥 Групповая работа** — совместное обучение
12. **📚 Оценки и МЭШ** — интеграция с электронным журналом
13. **🏆 Достижения и уровни** — геймификация
14. **🎨 Персональные рекомендации** — под интересы ученика
15. **📱 Оффлайн материалы** — ссылки для скачивания
16. **📤 Экспорт данных** — выгрузка результатов

## 🛠 Технологии

- **Python + FastAPI** — быстрый веб-сервер
- **GigaChat API (Сбер)** — российская нейросеть
- **Mini App формат** — бесшовная интеграция в MAX
- **Docker** — стабильное развертывание

```bash
pip install -r requirements.txt
