## 📖 О проекте

**Sferum Navigator** — это умный бот-помощник, встроенный в мессенджер MAX, который превращает привычный чат в персонального репетитора для школьника.

Бот не даёт готовых ответов — он **учит думать**: задаёт наводящие вопросы, объясняет темы простым языком, составляет планы подготовки к экзаменам и поддерживает мотивацию в трудные моменты. Всё это доступно **24/7**, **бесплатно** и **в любом регионе России**.

> 💡 **Миссия проекта:** дать каждому школьнику доступ к качественной образовательной поддержке, независимо от дохода семьи и места жительства.

| Не умеющие планировать подготовку | **58%** |

| Семей, не могущих позволить регулярные занятия | **62%** |

### Боль пользователей

**Школьники:**
- 😩 Не понимают материал, но стесняются спросить у учителя
- 😰 Паника перед ОГЭ/ЕГЭ, отсутствие плана подготовки
- 😤 Родители не могут помочь с домашкой
- 💸 Репетиторы дорогие и не всем доступны

**Родители:**
- 🕐 Устают проверять домашку каждый вечер

**Учителя:**
- 📝 Перегружены рутиной и проверками
- 👥 Не могут уделить время каждому из 30 учеников в классе

## 🚀 Возможности

### 📝 Помощь с домашкой (метод Сократа)
Бот **никогда не даёт готовый ответ**. Вместо этого он задаёт наводящие вопросы, помогая ученику прийти к решению самостоятельно. Это развивает критическое мышление и самостоятельность.

### 🖼️ Анализ фото заданий
Просто сфотографируй задачу, формулу или таблицу — бот прочитает изображение и поможет разобрать её. Используется **мультимодальная модель GigaChat**.

### 📅 Планировщик ОГЭ/ЕГЭ
Создай персональный план подготовки: бот разобьёт подготовку на этапы, подберёт темы и составит расписание с учётом доступного времени.

### 🎓 Объяснение тем
Сложные темы простым языком. Физика, математика, химия, история — бот объяснит любой предмет с примерами из жизни.

### ✅ Проверка знаний
Генерация тестов и квизов по любой теме. Бот создаст 5 вопросов с вариантами ответов и проверит знания.

### 🎥 Видеоуроки
Поиск видео по любой школьной теме на проверенных ресурсах.

### 💪 Мотивация
Бот-психолог: помогает справиться со стрессом, выгоранием и ленью. Поддерживает в трудные моменты.

### 📚 Оффлайн-материалы
Доступ к учебным ресурсам без интернета: Фоксфорд, Решу ЕГЭ, Учи.ру и другие.

### 🧠 Память диалога
Бот помнит контекст разговора с каждым учеником и учитывает его в ответах. Не нужно каждый раз объяснять, что именно не понятно.

## 🎓 Целевая аудитория

### Основные пользователи
| Аудитория | Возраст | Потребности |
|-----------|---------|-------------|
| **Школьники 5-11 классов** | 12-18 лет | Помощь с учёбой, подготовка к экзаменам |
| **Родители школьников** | 30-50 лет | Снятие стресса от домашки, контроль успеваемости |
| **Учителя** | 25-60 лет | Снижение нагрузки, автоматизация рутины |

### Вторичная аудитория
- Репетиторы (вспомогательный инструмент)
- Школьные администрации (цифровизация)
- Министерства образования (внедрение в школы)

## 🛠️ Технологии

### Основной стек

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| **Язык** | Python 3.11+ | Основной язык разработки |
| **ИИ-модель** | GigaChat API (Сбер) | Большая языковая модель, мультимодальность |
| **Мессенджер** | MAX (Сферум) | Платформа для общения с учениками |
| **Бот-фреймворк** | VK Bot API | Работа с сообщениями |
| **База данных** | SQLite / PostgreSQL | Хранение истории диалогов |
| **Хостинг** | Yandex Cloud | Соответствие ФЗ-152 о данных |

### Дополнительные технологии

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| **Веб-фреймворк** | FastAPI | REST API для будущих интеграций |
| **Кеширование** | Redis | Ускорение ответов |
| **CI/CD** | GitHub Actions | Автоматическое тестирование |
| **Мониторинг** | Yandex Monitoring | Отслеживание работы бота |
