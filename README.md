## 📖 О проекте

**Sferum Navigator** — умный бот-помощник для школьников, который помогает с домашкой, готовит к ОГЭ/ЕГЭ и поддерживает мотивацию. Бот использует ИИ-модель **GigaChat** от Сбера и работает в мессенджерах ВК и MAX.

### Возможности

| Функция | Описание |
|---------|----------|
| 📝 Помощь с домашкой | Метод Сократа — бот задаёт наводящие вопросы вместо готовых ответов |
| 🖼️ Анализ фото заданий | Отправь фото задачи — бот прочитает и поможет решить |
| 📅 Планировщик ОГЭ/ЕГЭ | Персональный план подготовки к экзаменам |
| 🎓 Объяснение тем | Сложные темы простым языком |
| ✅ Проверка знаний | Генерация тестов и квизов |
| 🎥 Видеоуроки | Поиск видео по любой теме |
| 💪 Мотивация | Поддержка при выгорании и стрессе |
| 🧠 Память диалога | Помнит контекст разговора с каждым учеником |
